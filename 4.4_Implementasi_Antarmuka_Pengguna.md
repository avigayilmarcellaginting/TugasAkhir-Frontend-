# 4.4 Implementasi Antarmuka Pengguna

Bagian ini menyajikan hasil implementasi antarmuka pengguna (*user interface*) dari aplikasi KasirPro UMKM (Avigayil POS). Antarmuka dikembangkan dengan pendekatan *mobile-first design* menggunakan teknologi **Vue 3 (Vite)**, **Tailwind CSS** untuk penataan visual, dan pustaka ikon **Remix Icon**. Desain antarmuka dirancang modern dengan konsep *glassmorphism*, skema warna harmoni (aksen *brand-600* biru/indigo), serta transisi animasi halus (*micro-animations*) untuk meningkatkan pengalaman pengguna (*User Experience*).

Berikut adalah rincian implementasi halaman-halaman utama beserta fungsionalitas dan detail teknisnya:

---

### 4.4.1 Halaman Onboarding (`OnboardingView.vue`)
*   **Fungsi**: Memperkenalkan fitur-fitur utama aplikasi kepada pengguna baru sebelum masuk ke sistem autentikasi.
*   **Elemen Visual**: Slide interaktif bergambar ikon fitur dengan efek bayangan mendalam (*shadow-xl*), tombol "Lewati" (*Skip*), pagination dots, dan tombol "Selanjutnya" / "Mulai Sekarang" (*Mulai Sekarang*).
*   **Detail Implementasi**:
    *   State `currentSlide` digunakan untuk memantau indeks slide aktif (0 hingga 2).
    *   Menggunakan data statis berupa array `slides` yang berisi judul, deskripsi, ikon (Remix Icon), dan skema warna visual.
    *   Fungsi `handleSkip` akan menyimpan penanda di `localStorage` (`hasSeenOnboarding = true`) agar pengguna tidak melihat onboarding lagi di sesi berikutnya, kemudian mengarahkan ke halaman `/auth`.

### 4.4.2 Halaman Autentikasi (`AuthView.vue`)
*   **Fungsi**: Gerbang masuk (*Login*) dan pendaftaran akun bisnis (*Register*) bagi pemilik usaha dan karyawan.
*   **Elemen Visual**: Form berbingkai dengan tepi melengkung (*rounded-xl*), transisi perpindahan dari Login ke Register, indikator langkah pendaftaran (Step 1 dan Step 2), input password aman, dan tombol status loading.
*   **Detail Implementasi**:
    *   **Proses Login**: Menggunakan form data reaktif `loginForm` (email, password). Memanggil API `/auth/login` menggunakan Axios. Jika sukses, menyimpan state user pada composable `useAuth` dan mengalihkan ke dashboard.
    *   **Proses Registrasi (Multi-Step)**:
        *   *Langkah 1 (Profil Usaha)*: Memasukkan Nama Usaha, Email Bisnis, Telepon, dan Alamat Usaha.
        *   *Langkah 2 (Profil Pemilik)*: Memasukkan Nama Lengkap, Email Login, Password, dan Konfirmasi Password.
        *   Form validasi aktif pada setiap langkah untuk meminimalkan input salah dari pengguna.

### 4.4.3 Halaman Dashboard Utama (`DashboardView.vue`)
*   **Fungsi**: Menampilkan ringkasan ringkas dan statistik operasional harian yang disesuaikan secara dinamis berdasarkan peran/hak akses pengguna.
*   **Elemen Visual**: Kartu omset bergradasi warna indigo (*from-brand-500 to-brand-600*), grid statistik ringkas (Laba Bersih, Transaksi, Pengeluaran), panel aksi cepat, log transaksi terbaru, dan peringatan stok menipis.
*   **Detail Implementasi**:
    *   Halaman ini menggunakan mekanisme penapisan berbasis hak akses (`can('dashboard-admin')` atau `can('dashboard-cashier')`).
    *   **Dashboard Admin (`AdminDashboard.vue`)**: Menampilkan statistik agregat dari cabang terpilih. Dilengkapi tombol navigasi cepat ke modul Kasir, Stok, Laporan, Karyawan, dan Promosi. Menampilkan daftar produk dengan stok di bawah ambang batas (<= 5 unit) beserta tombol *Restock* langsung.
    *   **Dashboard Kasir (`CashierDashboard.vue`)**: Menampilkan status shift saat ini (aktif/belum dimulai), tombol buka/tutup kasir dengan input modal cash awal (`StartShiftModal`, `EndShiftModal`), info jam kerja terjadwal, serta peringatan keterlambatan (jika masuk lewat dari jam jadwal).

### 4.4.4 Halaman Point of Sale / POS (`PosView.vue`)
*   **Fungsi**: Antarmuka kasir utama untuk memilih menu/produk, mengelola keranjang pemesanan, menghitung diskon, dan menyelesaikan pembayaran.
*   **Elemen Visual**: Header fixed bertema kaca (*glass-effect*), bilah pencarian produk (desktop & mobile), slide pill kategori produk, grid produk responsif dengan status stok, tombol cart mengambang (*floating cart bar*), panel keranjang belanja geser (`CartSheet.vue`), dan struk pembayaran digital (`ReceiptModal.vue`).
*   **Detail Implementasi**:
    *   **Pencarian & Filter**: Memanfaatkan computed property `filteredProducts` untuk menyaring daftar produk berdasarkan kata kunci pencarian dan kategori aktif secara real-time di sisi klien.
    *   **Keranjang Belanja (`CartSheet.vue`)**:
        *   *Tahap 1 (Keranjang)*: Mengelola jumlah produk yang dipesan dengan batasan stok. Integrasi composable `usePromotions` untuk memilih dan menerapkan kupon diskon.
        *   *Tahap 2 (Info Pelanggan)*: Memasukkan identitas pelanggan (Nama, Telepon, pilihan *Dine In* / *Take Away*, nomor meja, dan catatan khusus).
        *   *Tahap 3 (Pembayaran)*: Memilih metode pembayaran (Tunai, QRIS, dll.), input jumlah uang tunai dengan tombol cepat kelipatan nominal rupiah, dan penghitungan uang kembalian secara otomatis.
    *   **Modal Struk Pembayaran (`ReceiptModal.vue`)**:
        *   Menampilkan struk penjualan berdesain estetis dengan rincian pemesanan, diskon promo, pajak, total, pembayaran tunai, dan kembalian.
        *   Mendukung pencetakan langsung melalui browser (`window.print()`).
        *   Menyediakan fitur **Bluetooth Printer Integration** (`PrinterService.js`) untuk memindai, menghubungkan, dan mencetak struk secara wireless via perangkat mobile dengan pilihan ukuran kertas 58mm atau 80mm.

### 4.4.5 Halaman Inventaris / Manajemen Produk (`InventoryView.vue`)
*   **Fungsi**: Modul untuk menambah, mengubah, menghapus produk dan kategori, serta mengelola stok inventaris multi-cabang.
*   **Elemen Visual**: Tab navigasi (Produk vs Kategori), ringkasan data stok (Total Produk, Stok Tipis), tabel/grid produk dengan foto, badge stok, harga jual, dan harga pokok penjualan (HPP), serta form modal tambah/edit.
*   **Detail Implementasi**:
    *   **Kompresi Gambar Otomatis**: Memiliki fungsi kompresi gambar berbasis HTML5 Canvas (`compressImage`) untuk mereduksi ukuran file gambar produk yang diunggah di atas 1MB secara otomatis guna menghemat ruang penyimpanan server.
    *   **Pembaruan Stok (`StockForm`)**: Menangani penyesuaian stok per cabang dengan pilihan tipe aksi (set/tambah/kurang) untuk ketertelusuran yang lebih baik.

### 4.4.6 Halaman Manajemen Karyawan (`EmployeesView.vue`)
*   **Fungsi**: Memfasilitasi admin/pemilik dalam mengelola data karyawan, menetapkan cabang penugasan, mengatur jadwal jam kerja, dan menentukan hak akses modul.
*   **Elemen Visual**: List karyawan dengan inisial avatar berwarna, badge posisi/jabatan, form modal geser (*slide-up sheet*), pemilih jam kerja, dan daftar checkbox modul hak akses (*direct permissions*).
*   **Detail Implementasi**:
    *   Admin dapat mengonfigurasi properti karyawan seperti `work_start_at` (Mulai Kerja) dan `work_end_at` (Selesai Kerja) untuk pemantauan keterlambatan shift.
    *   Pengaturan hak akses (*permissions*) dilakukan secara modular per fitur (seperti akses modul kasir, stok, pengeluaran, laporan) yang akan disimpan langsung di database relasional backend.

### 4.4.7 Halaman Manajemen Promosi (`MarketingView.vue`)
*   **Fungsi**: Membuat dan mengelola kampanye diskon/promosi aktif untuk menstimulasi penjualan.
*   **Elemen Visual**: Banner pratinjau diskon dinamis (*Preview Diskon*) yang berubah sesuai dengan input form, daftar promo dengan badge status (Aktif, Berakhir, Pending, Non-Aktif), pemilih tipe diskon (persentase atau nominal rupiah tetap), dan minimal transaksi pembelian.
*   **Detail Implementasi**:
    *   Menghitung status promo secara dinamis berdasarkan tanggal hari ini dibandingkan dengan `start_date` dan `end_date` kampanye.
    *   Mendukung pembatasan jangkauan promosi, baik bersifat global (berlaku di semua outlet) maupun spesifik pada cabang tertentu (`branch_id`).

### 4.4.8 Halaman Laporan Keuangan (`FinanceView.vue` & `ReportsView.vue`)
*   **Fungsi**: Menyajikan visualisasi data penjualan, analisis laba rugi, log penutupan shift kasir, pencatatan pengeluaran, dan tren penjualan bisnis.
*   **Elemen Visual**: Grafik batang tren penjualan (CSS-based bar chart), list produk terlaris (*Top Products*), tab laporan (Ringkasan Laba Rugi, Arus Kas, Laporan Shift, Pengeluaran), kartu penawaran paket upgrade (Locked State CTA) bagi fitur tingkat lanjut.
*   **Detail Implementasi**:
    *   **Visualisasi Grafik**: `ReportsView.vue` menampilkan diagram batang interaktif harian menggunakan class Tailwind CSS dinamis (`h-[40%]`, `h-[95%]`, dll.) dengan tooltip nominal yang muncul ketika di-hover.
    *   **Kontrol Akses Fitur Premium**: Menerapkan validasi lisensi (`tab.locked = !can(tab.permission)`) untuk membatasi fitur lanjutan seperti Laba Rugi Detil dan Manajemen Pengeluaran untuk akun non-pro, sehingga menciptakan sistem monetisasi (*upselling*) langsung di dalam aplikasi kasir.
